                          KEY DATA FLOWS

1. USER SUBMITS QUERY
   Browser → /ws/voice WebSocket → FastAPI receives message

2. AGENT PERCEIVE PHASE
   Agent reads current world state (exceptions, ledger, bank feeds)
   → tool calls to API layer (get_exceptions, get_reconciliations, etc)
   → returns structured data to agent context

3. AGENT DECIDE PHASE
   Gemini Live LLM processes data + chat history
   → Streaming text output sent back to browser in real-time
   → Browser updates metric cards/progress bars on-the-fly

4. AGENT ACT PHASE
   LLM executes tool calls (post_journal_entry, notify_approver, etc)
   → Results fed back to LLM immediately
   → Loop continues until agent resolves or escalates to HITL

5. REAL-TIME METRICS UPDATED
   → Readiness % increases as checks pass
   → Exception count decreases
   → Sector times updated in lap chart
   → Latency metrics tracked in dashboard
