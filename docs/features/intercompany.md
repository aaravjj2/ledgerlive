# Intercompany

## Overview

This module provides the frontend interface for the Intercompany feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `IntercompanyPage` — Main page component
- `useIntercompany` — Data fetching hook

## Usage

Navigate to `/intercompany` in the application to access this feature.
