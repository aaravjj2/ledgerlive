# Forecasting

## Overview

This module provides the frontend interface for the Forecasting feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ForecastingPage` — Main page component
- `useForecasting` — Data fetching hook

## Usage

Navigate to `/forecasting` in the application to access this feature.
