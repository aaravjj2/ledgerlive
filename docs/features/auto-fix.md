# Auto-Fix

## Overview

This module provides the frontend interface for the Auto-Fix feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `AutoFixPage` — Main page component
- `useAutoFix` — Data fetching hook

## Usage

Navigate to `/auto-fix` in the application to access this feature.
