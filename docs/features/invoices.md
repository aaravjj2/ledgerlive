# Invoice Processing

## Overview

This module provides the frontend interface for the Invoice Processing feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `InvoicesPage` — Main page component
- `useInvoices` — Data fetching hook

## Usage

Navigate to `/invoices` in the application to access this feature.
