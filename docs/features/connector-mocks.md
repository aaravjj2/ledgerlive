# Connector Mocks

## Overview

This module provides the frontend interface for the Connector Mocks feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ConnectorMocksPage` — Main page component
- `useConnectorMocks` — Data fetching hook

## Usage

Navigate to `/connector-mocks` in the application to access this feature.
