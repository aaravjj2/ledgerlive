# JE Suggest

## Overview

This module provides the frontend interface for the JE Suggest feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `JeSuggestPage` — Main page component
- `useJeSuggest` — Data fetching hook

## Usage

Navigate to `/je-suggest` in the application to access this feature.
