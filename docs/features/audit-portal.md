# Audit Portal

## Overview

This module provides the frontend interface for the Audit Portal feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `AuditPortalPage` — Main page component
- `useAuditPortal` — Data fetching hook

## Usage

Navigate to `/audit-portal` in the application to access this feature.
