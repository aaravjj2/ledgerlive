# ML Baseline

## Overview

This module provides the frontend interface for the ML Baseline feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `MlBaselinePage` — Main page component
- `useMlBaseline` — Data fetching hook

## Usage

Navigate to `/ml-baseline` in the application to access this feature.
