# Depreciation

## Overview

This module provides the frontend interface for the Depreciation feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `DepreciationPage` — Main page component
- `useDepreciation` — Data fetching hook

## Usage

Navigate to `/depreciation` in the application to access this feature.
