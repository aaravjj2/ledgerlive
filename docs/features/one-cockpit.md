# One Cockpit

## Overview

This module provides the frontend interface for the One Cockpit feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `OneCockpitPage` — Main page component
- `useOneCockpit` — Data fetching hook

## Usage

Navigate to `/one-cockpit` in the application to access this feature.
