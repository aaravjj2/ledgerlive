# Cost Allocation

## Overview

This module provides the frontend interface for the Cost Allocation feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `CostAllocationPage` — Main page component
- `useCostAllocation` — Data fetching hook

## Usage

Navigate to `/cost-allocation` in the application to access this feature.
