# Evidence Search

## Overview

This module provides the frontend interface for the Evidence Search feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `EvidenceSearchPage` — Main page component
- `useEvidenceSearch` — Data fetching hook

## Usage

Navigate to `/evidence-search` in the application to access this feature.
