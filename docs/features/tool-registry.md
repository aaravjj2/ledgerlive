# Tool Registry

## Overview

This module provides the frontend interface for the Tool Registry feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ToolRegistryPage` — Main page component
- `useToolRegistry` — Data fetching hook

## Usage

Navigate to `/tool-registry` in the application to access this feature.
