# ABAC Engine

## Overview

This module provides the frontend interface for the ABAC Engine feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `AbacPage` — Main page component
- `useAbac` — Data fetching hook

## Usage

Navigate to `/abac` in the application to access this feature.
