# Fixed Assets

## Overview

This module provides the frontend interface for the Fixed Assets feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `FixedAssetsPage` — Main page component
- `useFixedAssets` — Data fetching hook

## Usage

Navigate to `/fixed-assets` in the application to access this feature.
