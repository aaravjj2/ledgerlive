# Role Permissions

## Overview

This module provides the frontend interface for the Role Permissions feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `RolesPage` — Main page component
- `useRoles` — Data fetching hook

## Usage

Navigate to `/roles` in the application to access this feature.
