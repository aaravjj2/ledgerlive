# Data Lake Export

## Overview

This module provides the frontend interface for the Data Lake Export feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `DataLakePage` — Main page component
- `useDataLake` — Data fetching hook

## Usage

Navigate to `/data-lake` in the application to access this feature.
