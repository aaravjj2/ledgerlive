# Airia Adapter

## Overview

This module provides the frontend interface for the Airia Adapter feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `AiriaAdapterPage` — Main page component
- `useAiriaAdapter` — Data fetching hook

## Usage

Navigate to `/airia-adapter` in the application to access this feature.
