# Covenants

## Overview

This module provides the frontend interface for the Covenants feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `CovenantsPage` — Main page component
- `useCovenants` — Data fetching hook

## Usage

Navigate to `/covenants` in the application to access this feature.
