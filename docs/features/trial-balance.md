# Trial Balance

## Overview

This module provides the frontend interface for the Trial Balance feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `TrialBalancePage` — Main page component
- `useTrialBalance` — Data fetching hook

## Usage

Navigate to `/trial-balance` in the application to access this feature.
