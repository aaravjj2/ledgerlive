# Data Export

## Overview

This module provides the frontend interface for the Data Export feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `DataExportPage` — Main page component
- `useDataExport` — Data fetching hook

## Usage

Navigate to `/data-export` in the application to access this feature.
