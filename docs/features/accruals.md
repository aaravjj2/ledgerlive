# Accruals & Deferrals

## Overview

This module provides the frontend interface for the Accruals & Deferrals feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `AccrualsPage` — Main page component
- `useAccruals` — Data fetching hook

## Usage

Navigate to `/accruals` in the application to access this feature.
