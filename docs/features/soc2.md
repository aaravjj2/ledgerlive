# SOC2 Evidence

## Overview

This module provides the frontend interface for the SOC2 Evidence feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `Soc2Page` — Main page component
- `useSoc2` — Data fetching hook

## Usage

Navigate to `/soc2` in the application to access this feature.
