# Triage Queue

## Overview

This module provides the frontend interface for the Triage Queue feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `TriageQueuePage` — Main page component
- `useTriageQueue` — Data fetching hook

## Usage

Navigate to `/triage-queue` in the application to access this feature.
