# Payment Runs

## Overview

This module provides the frontend interface for the Payment Runs feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `PaymentsPage` — Main page component
- `usePayments` — Data fetching hook

## Usage

Navigate to `/payments` in the application to access this feature.
