# Financial Statements

## Overview

This module provides the frontend interface for the Financial Statements feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `FinancialStatementsPage` — Main page component
- `useFinancialStatements` — Data fetching hook

## Usage

Navigate to `/financial-statements` in the application to access this feature.
