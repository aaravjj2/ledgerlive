# Trace Explorer

## Overview

This module provides the frontend interface for the Trace Explorer feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `TraceExplorerPage` — Main page component
- `useTraceExplorer` — Data fetching hook

## Usage

Navigate to `/trace-explorer` in the application to access this feature.
