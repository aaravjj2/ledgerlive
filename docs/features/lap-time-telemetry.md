# Lap Time Telemetry

## Overview

This module provides the frontend interface for the Lap Time Telemetry feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `LapTimeTelemetryPage` — Main page component
- `useLapTimeTelemetry` — Data fetching hook

## Usage

Navigate to `/lap-time-telemetry` in the application to access this feature.
