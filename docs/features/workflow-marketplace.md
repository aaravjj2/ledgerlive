# Workflow Marketplace

## Overview

This module provides the frontend interface for the Workflow Marketplace feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `WorkflowMarketplacePage` — Main page component
- `useWorkflowMarketplace` — Data fetching hook

## Usage

Navigate to `/workflow-marketplace` in the application to access this feature.
