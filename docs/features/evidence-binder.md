# Evidence Binder

## Overview

This module provides the frontend interface for the Evidence Binder feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `EvidenceBinderPage` — Main page component
- `useEvidenceBinder` — Data fetching hook

## Usage

Navigate to `/evidence-binder` in the application to access this feature.
