# Notifications

## Overview

This module provides the frontend interface for the Notifications feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `NotificationsPage` — Main page component
- `useNotifications` — Data fetching hook

## Usage

Navigate to `/notifications` in the application to access this feature.
