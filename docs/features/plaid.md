# Plaid Connector

## Overview

This module provides the frontend interface for the Plaid Connector feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `PlaidPage` — Main page component
- `usePlaid` — Data fetching hook

## Usage

Navigate to `/plaid` in the application to access this feature.
