# Security Scoreboard

## Overview

This module provides the frontend interface for the Security Scoreboard feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `SecurityScoreboardPage` — Main page component
- `useSecurityScoreboard` — Data fetching hook

## Usage

Navigate to `/security-scoreboard` in the application to access this feature.
