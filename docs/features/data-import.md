# Data Import

## Overview

This module provides the frontend interface for the Data Import feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `DataImportPage` — Main page component
- `useDataImport` — Data fetching hook

## Usage

Navigate to `/data-import` in the application to access this feature.
