# Chart of Accounts

## Overview

This module provides the frontend interface for the Chart of Accounts feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ChartOfAccountsPage` — Main page component
- `useChartOfAccounts` — Data fetching hook

## Usage

Navigate to `/chart-of-accounts` in the application to access this feature.
