# Gradient Adapter

## Overview

This module provides the frontend interface for the Gradient Adapter feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `GradientAdapterPage` — Main page component
- `useGradientAdapter` — Data fetching hook

## Usage

Navigate to `/gradient-adapter` in the application to access this feature.
