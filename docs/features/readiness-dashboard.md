# Readiness Dashboard

## Overview

This module provides the frontend interface for the Readiness Dashboard feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ReadinessDashboardPage` — Main page component
- `useReadinessDashboard` — Data fetching hook

## Usage

Navigate to `/readiness-dashboard` in the application to access this feature.
