# Admin Console

## Overview

This module provides the frontend interface for the Admin Console feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `AdminConsolePage` — Main page component
- `useAdminConsole` — Data fetching hook

## Usage

Navigate to `/admin-console` in the application to access this feature.
