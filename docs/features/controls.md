# Controls Catalog

## Overview

This module provides the frontend interface for the Controls Catalog feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ControlsPage` — Main page component
- `useControls` — Data fetching hook

## Usage

Navigate to `/controls` in the application to access this feature.
