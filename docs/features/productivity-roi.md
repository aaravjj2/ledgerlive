# Productivity ROI

## Overview

This module provides the frontend interface for the Productivity ROI feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ProductivityRoiPage` — Main page component
- `useProductivityRoi` — Data fetching hook

## Usage

Navigate to `/productivity-roi` in the application to access this feature.
