# Mapping Studio

## Overview

This module provides the frontend interface for the Mapping Studio feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `MappingStudioPage` — Main page component
- `useMappingStudio` — Data fetching hook

## Usage

Navigate to `/mapping-studio` in the application to access this feature.
