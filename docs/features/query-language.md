# Query Language

## Overview

This module provides the frontend interface for the Query Language feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `QueryLanguagePage` — Main page component
- `useQueryLanguage` — Data fetching hook

## Usage

Navigate to `/query-language` in the application to access this feature.
