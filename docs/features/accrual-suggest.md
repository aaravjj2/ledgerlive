# Accrual Suggest

## Overview

This module provides the frontend interface for the Accrual Suggest feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `AccrualSuggestPage` — Main page component
- `useAccrualSuggest` — Data fetching hook

## Usage

Navigate to `/accrual-suggest` in the application to access this feature.
