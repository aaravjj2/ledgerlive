# Expense Reports

## Overview

This module provides the frontend interface for the Expense Reports feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ExpensesPage` — Main page component
- `useExpenses` — Data fetching hook

## Usage

Navigate to `/expenses` in the application to access this feature.
