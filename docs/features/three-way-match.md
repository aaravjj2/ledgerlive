# Three-Way Match

## Overview

This module provides the frontend interface for the Three-Way Match feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ThreeWayMatchPage` — Main page component
- `useThreeWayMatch` — Data fetching hook

## Usage

Navigate to `/three-way-match` in the application to access this feature.
