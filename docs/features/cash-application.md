# Cash Application

## Overview

This module provides the frontend interface for the Cash Application feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `CashApplicationPage` — Main page component
- `useCashApplication` — Data fetching hook

## Usage

Navigate to `/cash-application` in the application to access this feature.
