# Vendor Management

## Overview

This module provides the frontend interface for the Vendor Management feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `VendorsPage` — Main page component
- `useVendors` — Data fetching hook

## Usage

Navigate to `/vendors` in the application to access this feature.
