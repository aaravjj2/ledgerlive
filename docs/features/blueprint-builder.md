# Blueprint Builder

## Overview

This module provides the frontend interface for the Blueprint Builder feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `BlueprintBuilderPage` — Main page component
- `useBlueprintBuilder` — Data fetching hook

## Usage

Navigate to `/blueprint-builder` in the application to access this feature.
