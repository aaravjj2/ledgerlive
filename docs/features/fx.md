# FX Translation

## Overview

This module provides the frontend interface for the FX Translation feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `FxPage` — Main page component
- `useFx` — Data fetching hook

## Usage

Navigate to `/fx` in the application to access this feature.
