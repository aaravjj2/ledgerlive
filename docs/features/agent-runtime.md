# Agent Runtime

## Overview

This module provides the frontend interface for the Agent Runtime feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `AgentRuntimePage` — Main page component
- `useAgentRuntime` — Data fetching hook

## Usage

Navigate to `/agent-runtime` in the application to access this feature.
