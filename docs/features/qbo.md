# QuickBooks Connector

## Overview

This module provides the frontend interface for the QuickBooks Connector feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `QboPage` — Main page component
- `useQbo` — Data fetching hook

## Usage

Navigate to `/qbo` in the application to access this feature.
