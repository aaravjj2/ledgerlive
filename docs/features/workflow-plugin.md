# Workflow Plugin

## Overview

This module provides the frontend interface for the Workflow Plugin feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `WorkflowPluginPage` — Main page component
- `useWorkflowPlugin` — Data fetching hook

## Usage

Navigate to `/workflow-plugin` in the application to access this feature.
