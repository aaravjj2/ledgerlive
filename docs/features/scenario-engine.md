# Scenario Engine

## Overview

This module provides the frontend interface for the Scenario Engine feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ScenarioEnginePage` — Main page component
- `useScenarioEngine` — Data fetching hook

## Usage

Navigate to `/scenario-engine` in the application to access this feature.
