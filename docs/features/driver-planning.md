# Driver Planning

## Overview

This module provides the frontend interface for the Driver Planning feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `DriverPlanningPage` — Main page component
- `useDriverPlanning` — Data fetching hook

## Usage

Navigate to `/driver-planning` in the application to access this feature.
