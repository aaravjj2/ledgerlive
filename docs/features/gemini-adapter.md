# Gemini Adapter

## Overview

This module provides the frontend interface for the Gemini Adapter feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `GeminiAdapterPage` — Main page component
- `useGeminiAdapter` — Data fetching hook

## Usage

Navigate to `/gemini-adapter` in the application to access this feature.
