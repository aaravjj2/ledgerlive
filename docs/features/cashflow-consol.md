# Cash Flow Consolidation

## Overview

This module provides the frontend interface for the Cash Flow Consolidation feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `CashflowConsolPage` — Main page component
- `useCashflowConsol` — Data fetching hook

## Usage

Navigate to `/cashflow-consol` in the application to access this feature.
