# Pit Stop Optimizer

## Overview

This module provides the frontend interface for the Pit Stop Optimizer feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `PitStopOptimizerPage` — Main page component
- `usePitStopOptimizer` — Data fetching hook

## Usage

Navigate to `/pit-stop-optimizer` in the application to access this feature.
