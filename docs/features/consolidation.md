# Consolidation

## Overview

This module provides the frontend interface for the Consolidation feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ConsolidationPage` — Main page component
- `useConsolidation` — Data fetching hook

## Usage

Navigate to `/consolidation` in the application to access this feature.
