# Close Period

## Overview

This module provides the frontend interface for the Close Period feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ClosePeriodPage` — Main page component
- `useClosePeriod` — Data fetching hook

## Usage

Navigate to `/close-period` in the application to access this feature.
