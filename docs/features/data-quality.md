# Data Quality

## Overview

This module provides the frontend interface for the Data Quality feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `DataQualityPage` — Main page component
- `useDataQuality` — Data fetching hook

## Usage

Navigate to `/data-quality` in the application to access this feature.
