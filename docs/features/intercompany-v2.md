# Intercompany V2

## Overview

This module provides the frontend interface for the Intercompany V2 feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `IntercompanyV2Page` — Main page component
- `useIntercompanyV2` — Data fetching hook

## Usage

Navigate to `/intercompany-v2` in the application to access this feature.
