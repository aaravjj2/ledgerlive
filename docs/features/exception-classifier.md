# Exception Classifier

## Overview

This module provides the frontend interface for the Exception Classifier feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ExceptionClassifierPage` — Main page component
- `useExceptionClassifier` — Data fetching hook

## Usage

Navigate to `/exception-classifier` in the application to access this feature.
