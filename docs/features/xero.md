# Xero Connector

## Overview

This module provides the frontend interface for the Xero Connector feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `XeroPage` — Main page component
- `useXero` — Data fetching hook

## Usage

Navigate to `/xero` in the application to access this feature.
