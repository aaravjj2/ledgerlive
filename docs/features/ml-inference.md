# ML Inference

## Overview

This module provides the frontend interface for the ML Inference feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `MlInferencePage` — Main page component
- `useMlInference` — Data fetching hook

## Usage

Navigate to `/ml-inference` in the application to access this feature.
