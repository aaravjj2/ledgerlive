# User Management

## Overview

This module provides the frontend interface for the User Management feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `UsersPage` — Main page component
- `useUsers` — Data fetching hook

## Usage

Navigate to `/users` in the application to access this feature.
