# Close Management

## Overview

This module provides the frontend interface for the Close Management feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `CloseMgmtPage` — Main page component
- `useCloseMgmt` — Data fetching hook

## Usage

Navigate to `/close-mgmt` in the application to access this feature.
