# ML Dataset

## Overview

This module provides the frontend interface for the ML Dataset feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `MlDatasetPage` — Main page component
- `useMlDataset` — Data fetching hook

## Usage

Navigate to `/ml-dataset` in the application to access this feature.
