# Lease Accounting

## Overview

This module provides the frontend interface for the Lease Accounting feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `LeasesPage` — Main page component
- `useLeases` — Data fetching hook

## Usage

Navigate to `/leases` in the application to access this feature.
