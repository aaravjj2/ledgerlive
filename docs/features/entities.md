# Entities

## Overview

This module provides the frontend interface for the Entities feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `EntitiesPage` — Main page component
- `useEntities` — Data fetching hook

## Usage

Navigate to `/entities` in the application to access this feature.
