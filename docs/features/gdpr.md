# GDPR Redaction

## Overview

This module provides the frontend interface for the GDPR Redaction feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `GdprPage` — Main page component
- `useGdpr` — Data fetching hook

## Usage

Navigate to `/gdpr` in the application to access this feature.
