# Approval Workflows

## Overview

This module provides the frontend interface for the Approval Workflows feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `ApprovalsPage` — Main page component
- `useApprovals` — Data fetching hook

## Usage

Navigate to `/approvals` in the application to access this feature.
