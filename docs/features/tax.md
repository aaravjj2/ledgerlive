# Tax Compliance

## Overview

This module provides the frontend interface for the Tax Compliance feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `TaxPage` — Main page component
- `useTax` — Data fetching hook

## Usage

Navigate to `/tax` in the application to access this feature.
