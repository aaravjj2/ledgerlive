# KPI Framework

## Overview

This module provides the frontend interface for the KPI Framework feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `KpiPage` — Main page component
- `useKpi` — Data fetching hook

## Usage

Navigate to `/kpi` in the application to access this feature.
