# Lineage Manifest

## Overview

This module provides the frontend interface for the Lineage Manifest feature.

## API Endpoints

- `GET /api/...` — List items
- `POST /api/...` — Create item
- `GET /api/.../{id}` — Get item
- `PUT /api/.../{id}` — Update item
- `DELETE /api/.../{id}` — Delete item

## Components

- `LineagePage` — Main page component
- `useLineage` — Data fetching hook

## Usage

Navigate to `/lineage` in the application to access this feature.
